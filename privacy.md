This is a static website without any JavaScript, cookies or third party resources. It uses very little <a href='/assets/css/main.css'>CSS</a> necessary to be responsive to your screen size. The website is hosted by <a href='https://www.fastmail.com/about/privacy/'>Fastmail</a> which provides me a standard log file containing timestamp, hostname, page, referer and UserAgent for the past two weeks. Like this:

```
2022-05-11T03:56:18Z,www.svensemmler.org,/404.html,https://www.svensemmler.org/,"Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/101.0.4951.64 Safari/537.36"
```

I do not archive nor analyse these logs. If you want me to know that you saw my pages feel free to send me an <a href='mailto:Sven@SvenSemmler.org'>email</a>.
